this project is an ocr that aims to train a vlm to recognize handwritten notes and transcript them into text file.
Feel free to use this project.

The neural_network folder contains the files that build the weights of the ai.
The neural network used here will be a vlm based on the transformer architecture.
More precisely, the architecture is a bit similar to Paddle-OCR from baidu




The software folder contains the files that that will read the caracters
